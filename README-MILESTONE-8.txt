## Install targeted patch
Merge the included `src` folder into your existing portfolio and replace files when prompted. The patch includes `src/app/skills/page.tsx`, `src/app/globals.css`, and the new `src/components/SkillsExperience.tsx`. No package changes or new dependencies are required.

Run `npm.cmd run dev` and visit `http://localhost:3000/skills/`.
